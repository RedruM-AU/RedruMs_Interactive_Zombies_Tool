General

The basics.

What is RedruM's Interactive Zombies Tool?

It connects your TikTok LIVE stream directly to Call of Duty Zombies. Viewer likes, gifts, and chat commands trigger real in-game effects while you play.

Which games does it support?

Black Ops 3 Zombies (Steam), Black Ops 2 Zombies (Plutonium T6), and Black Ops 1 Zombies (Plutonium T5) - all full support. The app auto-detects which game is running and switches profiles automatically.

How It Works

What viewers actually trigger.

What happens when someone likes my stream?

Every 1,000 likes gives +1,000 in-game points; every 5,000 likes triggers a bonus random spin.

What do gifts do?

Each gift is mapped to an in-game action that fires instantly - fully customizable via the Gift Routing Matrix.

What does !spin do?

A chat command that rolls a weighted random effect from your configured pool. 10-minute cooldown normally, 3 minutes for people who've gifted.

Do gifters get anything extra?

Yes - faster !spin cooldown, and their chat messages get read aloud via TTS.

Setup

Getting it running.

What do I need to install for Black Ops 3?

The [ZM] Sphynx' Console Commands mod, and BO3 must be in Windowed (Borderless) mode. Play on a controller since the bot uses your keyboard for commands.

What do I need to install for Plutonium (T5/T6)?

Export and place the GSC script in the correct Plutonium scripts folder, then load the exported binds .cfg in-game via console.

Do I need to be the lobby host in Plutonium?

Yes - the GSC script only runs for whoever is hosting the lobby.

Does it work in fullscreen?

No - fullscreen blocks keypresses. Use Borderless (Windowed Borderless for BO3, or Borderless Gaming for Plutonium).

Do I need to go live before launching the bot?

Yes - go live on TikTok first, then click Launch.

Troubleshooting

When something's not working.

Keys aren't working in BO3.

Confirm BO3 is Windowed (Borderless) and focused, run the bot as Administrator, confirm the Sphynx mod is active, and re-run /exec binds.cfg in console.

Nothing happens in Plutonium.

Re-run the exec command in console, confirm you're the host, confirm the GSC file is in the right folder (run map_restart after placing it), and make sure you're using Borderless Gaming.

I see !botcmd text on my HUD in Plutonium.

Disable text chat display in Plutonium's in-game settings - the GSC still receives every command regardless.

The bot won't connect to TikTok.

You must be actively LIVE before launching. Double check your TikTok handle on the Dashboard.

There's no TTS voice.

Check the Mute TTS button on the Dashboard, and check volume/voice/TTS toggles in Settings.

I changed a key bind and it's not working.

Save Configuration after changing it in Action Binds, then re-run the exec command in-game again.

I see a Windows Defender / SmartScreen warning.

This is a false positive - the program simulates keyboard input and reads TikTok LIVE data, which trips antivirus heuristics on otherwise-safe software. Click More Info → Run Anyway, or let the installer add a Defender exclusion for you.

OBS Overlay Setup

Getting stats on stream.

How do I turn on the OBS overlay?

Settings tab → OBS Overlay section → tick "Write live stats for OBS." Stats update to text files roughly once a second while it's on.

How do I actually get the stats into OBS?

In OBS, add a Text (GDI+) Source → tick "Read from file" → browse to the overlay folder and pick the stat file you want (e.g. likes.txt, gifts.txt, top_gifter.txt). Each stat is its own file, so add a separate Text source per stat you want on screen.

Where do I find the overlay files?

Settings → OBS Overlay → "Open Overlay Folder" button opens it directly. It lives at %APPDATA%\BO3TikTokBot\overlay\.

What stats are available?

Likes, viewers, gifts, coins, spins, follows, uptime, likes-per-minute, bonus-spin progress, last gift, last spin, last follower, top gifter, a rolling recent-chat feed, live status, and (optionally) Spotify now-playing - each as its own .txt file.

Can I show what song I'm playing on stream?

Yes - tick "Include Spotify now-playing" underneath the main OBS overlay checkbox (requires the main "Write live stats for OBS" toggle to be on too). It reads the track info straight from the Spotify desktop app's window title - no login, API key, or extra setup needed. Spotify just needs to be open and playing on the same PC.

My OBS text source isn't updating.

Confirm "Write live stats for OBS" is ticked in Settings, confirm the Text source in OBS has "Read from file" enabled and is pointed at the correct file in the overlay folder, and confirm the bot is actually running/live (files only update while a session is active).

Privacy & Safety

What it does and doesn't touch.

Does this read my TikTok login or password?

No - it only reads public TikTok LIVE event data (likes, gifts, follows, chat). No login/credentials required.

Does it modify my game files permanently?

No - it only adds a keybind config and (for Plutonium) a GSC script, both of which you can remove manually. No core game files are touched.

Uninstalling

If you ever want to leave.

How do I uninstall?

Settings → Apps → RedruM's Interactive Zombies Tool → Uninstall. You'll be asked whether to keep your settings/stats. GSC and cfg files in your game folders stay unless you delete them manually.

If I reinstall, do I lose my settings?

Not if you chose to keep them during uninstall - config is preserved and versions carry it forward automatically.
