General

The basics.

What is RedruM's Interactive Zombies Tool?

It connects your TikTok LIVE stream directly to Call of Duty Zombies. Viewer likes, gifts, and chat commands trigger real in-game effects while you play.

Which games does it support?

Black Ops 3 Zombies on Steam, Black Ops 2 Zombies on Plutonium T6, and Black Ops 1 Zombies on Plutonium T5. Choose the matching game profile. The app shows whether it detects the selected game window.

How It Works

What viewers actually trigger.

What happens when someone likes my stream?

You can configure points and bonus spins at your chosen like thresholds under Settings → Gameplay.

What do gifts do?

Mapped gifts trigger the game action you assign under Actions & Gifts → Gift mappings.

What does !spin do?

It rolls a weighted effect from your configured wheel. You can adjust the normal and gifter cooldowns in Settings → Gameplay.

Do gifters get anything extra?

You can give gifters a shorter spin cooldown and enable voice callouts in the app settings.

Setup

Getting it running.

Start with the game setup guide for your game's console command and Max Ammo test.

What do I need to install for Black Ops 3?

Load Sphynx Console Commands v1.0.6 and use Windowed (Borderless) mode. The app sends keyboard binds. If you play with keyboard and mouse, choose action keys that do not overlap your game controls.

What do I need to install for Plutonium (T5/T6)?

Select your game in Setup, find the game folders, and install the game files. Host a match, open the console with the key below Esc, and run the command shown in Setup.

Do I need to be the lobby host in Plutonium?

Yes - the GSC script only runs for whoever is hosting the lobby.

How do I open or customise the BO1 or BO2 in-game menu?

While hosting a Zombies match, hold Aim and press Melee. Choose Interactive Settings > Menu Appearance for themes and placement. The setup guide lists the full controls and how to save defaults.

Does it work in fullscreen?

Use windowed or borderless mode. Exclusive fullscreen can interfere with the app's key delivery.

Do I need to go live before launching the bot?

You can open the tool and test your setup offline. Start your TikTok LIVE before you select Connect to TikTok.

Troubleshooting

When something's not working.

Keys aren't working in BO3.

Check the game profile, confirm BO3 is windowed or borderless and the Sphynx mod is active, then run /exec binds.cfg and close the console. Click Test Max Ammo bind and return to the game within three seconds.

Nothing happens in Plutonium.

Make sure you are hosting and the game files are installed. Start a fresh match after updating the script, rerun the bind command in the game console, and close the console before testing.

I see !botcmd text on my HUD in Plutonium.

Disable text chat display in Plutonium's in-game settings - the GSC still receives every command regardless.

The bot won't connect to TikTok.

Confirm your TikTok LIVE has started and the username on Live is correct. Use Diagnostics → Copy diagnostics to share details if the problem continues.

There's no TTS voice.

Open Settings → TTS and OBS. Check your voice, volume and mute settings, then select Test voice.

I changed a key bind and it's not working.

Click Save profile in Actions & Gifts, reinstall the game files from Setup, and rerun the bind command in the game console.

I see a Windows Defender / SmartScreen warning.

The installer is unsigned, so Windows may show a SmartScreen warning. Download from the official GitHub release and compare your download's SHA-256 with the release notes. Keep Microsoft Defender enabled.

OBS Overlay Setup

Getting stats on stream.

How do I turn on the OBS overlay?

Open Settings → TTS and OBS and tick Write OBS text files.

How do I actually get the stats into OBS?

In OBS, add a Text (GDI+) Source → tick "Read from file" → browse to the overlay folder and pick the stat file you want (e.g. likes.txt, gifts.txt, top_gifter.txt). Each stat is its own file, so add a separate Text source per stat you want on screen.

Where do I find the overlay files?

In Settings → TTS and OBS, select Copy OBS folder path after enabling text files. Paste that path into the file picker in OBS. If you upgraded from 2.7.0, point your existing OBS sources to this folder.

What stats are available?

Likes, viewers, gifts, coins, spins, follows, uptime, likes-per-minute, bonus-spin progress, last gift, last spin, last follower, top gifter, a rolling recent-chat feed, live status, and (optionally) Spotify now-playing - each as its own .txt file.

Can I show what song I'm playing on stream?

In Settings → TTS and OBS, tick Write OBS text files and Include Spotify now playing. Start playback in the Spotify desktop app on the same PC and point an OBS Text source to spotify_now_playing.txt.

My OBS text source isn't updating.

Confirm Write OBS text files is on. In OBS, enable Read from file for the Text source and use the path from Copy OBS folder path.

Privacy & Safety

What it does and doesn't touch.

Does this read my TikTok login or password?

No - it only reads public TikTok LIVE event data (likes, gifts, follows, chat). No login/credentials required.

Does it modify my game files permanently?

No - it only adds a keybind config and (for Plutonium) a GSC script, both of which you can remove manually. No core game files are touched.

Uninstalling

If you ever want to leave.

How do I uninstall?

Open Windows Settings → Apps, select RedruM's Interactive Zombies Tool, and choose Uninstall.

If I reinstall, do I lose my settings?

Saved settings and stats are kept for a future reinstall. Close the app before running Setup over your existing installation.
