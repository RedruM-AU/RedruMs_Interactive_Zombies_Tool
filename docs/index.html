Get Started

Live in three steps.

Full per-game setup (mods, GSC files, binds) is in the README.

  1. Download & install

    Grab the installer from GitHub Releases. Close the game and app, extract the ZIP, and run Setup. Compatible settings carry over.

  2. Set up and test your game

    Select your game in Setup. Find the folders, install the game files, and run the bind command in the match. Then click Test Max Ammo bind and return to the game within three seconds.

  3. Connect to TikTok

    Start your TikTok LIVE, enter your username, and select Connect to TikTok. With game input on, actions go to the verified game window.
