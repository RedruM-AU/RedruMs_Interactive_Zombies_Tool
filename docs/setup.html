Set up your Zombies game

Install the game files, load your binds, and test an action before connecting to TikTok.

BO3 Steam BO2 Plutonium T6 BO1 Plutonium T5

Install the game files

  1. Download the current Windows Setup from GitHub Releases, then run the installer. If you downloaded the ZIP, extract it first. Open the app under your normal Windows account.
  2. Open the tool, select your game profile, and open Setup.
  3. If you edit a key, open Actions & Gifts → Keybinds, use Search actions to find it, and select Save profile. Avoid F10, F12 and Home on Plutonium.
  4. Select Find game folders, check the paths, and select Install game files. Use Browse if the folders are missing. If Setup lists a keybind conflict, change the listed keys in Actions & Gifts → Keybinds and save the profile before installing.

The Game files installed dialog lists the files that were written. Select Copy command to copy the console command for your game. If existing files were backed up, Open backup folder opens that install’s backup.

You can install game files while the selected game is open if the app is idle. End the stream, demo, or test first. The startup updater skips games that are open.

Black Ops 3 Zombies Steam

Install the game files, load Sphynx Console Commands v1.0.6, and start a Zombies match in windowed or borderless mode.

Open the console with the console key, usually below Esc (tilde on US keyboards). Run this command and close the console.

/exec binds.cfg

Test Max Ammo

Add a custom BO3 action

  1. Open Actions & Gifts → Keybinds → Add BO3 action. Enter a name, choose an unused key, and paste a command such as /namedzombie 5.
  2. Check the live Bind preview. The generated bind uses namedzombie 5.
  3. Select Save profile, then Setup → Install game files. In a Zombies match with Sphynx loaded, run /exec binds.cfg again.
  4. Try the physical key first. To use it on stream, select the action in Gift mappings, save, and use Test gift.

Sphynx command list on Steam Workshop

Use Edit duration or Edit spawn count when they appear for a supported command. See BO3 Keybinds.

Use Settings → Gameplay → BO3 effects and repeats for app-managed timers. Changes there apply to the next session or test.

Black Ops 2 Zombies Plutonium T6

In Setup, select Install game files for BO2. If the dialog says the Zombies script changed, restart the map or host a new match before running the command below. For bind-only changes, rerun the command in the same match. Use windowed or borderless mode.

Press the key below Esc to open the console. Run this command and close the console.

Test Max Ammo

Test an action and go live

  1. With game input enabled, select Test Max Ammo bind in Setup and return to your match within three seconds.
  2. Look for an ammo refill or a Max Ammo message. If nothing happens, check that Setup detects the selected game, run the bind command again, and close the console before testing.
  3. Once the test works, you can tick I saw Max Ammo in the game. Select Next: Connect to TikTok to open Live.
  4. Start your TikTok LIVE, enter your username in the tool, and select Connect to TikTok.

Still stuck? Check the troubleshooting FAQ or open Diagnostics → Copy diagnostics and share the result in Discord.

BO1 and BO2 in-game menu

While hosting a Zombies match, hold Aim and press Melee to open the menu. Tap Aim for next, Jump for previous, Use/Reload to select and Melee to go back or close.

In-game — Open Interactive Settings > Menu Appearance to change the colour theme or move the panel left, centre or right for the current match.

In the app — Save defaults for future matches under Settings > Appearance > Configure in-game HUD. Return to Setup and select Install game files. Restart the map or start a new match before reloading your binds.
