Set up your Zombies game

Install the game files, load your binds, and test an action before connecting to TikTok.

BO3 Steam BO2 Plutonium T6 BO1 Plutonium T5

Install the game files

  1. Download Windows Setup from GitHub Releases, then run the installer. If you downloaded the ZIP, extract it first. Open the app under your normal Windows account.
  2. Open the tool, select your game profile, and open Setup.
  3. Select Find game folders, check the paths, and select Install game files. If the folders aren’t found, select them with Browse.

Black Ops 3 Zombies Steam

Install the game files, load Sphynx Console Commands v1.0.6, and start a Zombies match in windowed or borderless mode.

Open the console with the console key, usually below Esc (tilde on US keyboards). Run this command and close the console.

/exec binds.cfg

Black Ops 2 Zombies Plutonium T6

Press the key below Esc to open the console. Run this command and close the console.

Black Ops 1 Zombies Plutonium T5

exec pluto_t5_binds.cfg

Test Max Ammo

Test an action and go live

  1. With game input enabled, select Test Max Ammo bind in Setup and return to your match within three seconds.
  2. Look for an ammo refill or a Max Ammo message. If nothing happens, check that Setup detects the selected game, run the bind command again, and close the console before testing.
  3. Once the test works, you can tick I saw Max Ammo in the game. Select Next: Connect to TikTok to open Live.
  4. Start your TikTok LIVE, enter your username in the tool, and select Connect to TikTok.

Still stuck? Check the troubleshooting FAQ or open Diagnostics → Copy diagnostics and share the result in Discord.

BO1 and BO2 in-game menu

While hosting a Zombies match, hold Aim and press Melee to open the menu. Tap Aim for next, Jump for previous, Use/Reload to select and Melee to go back or close.

In-game — Open Interactive Settings > Menu Appearance to change the colour theme or move the panel left, centre or right for the current match.

In the app — Save defaults for future matches under Settings > Appearance > Configure in-game HUD. With the game closed, return to Setup and select Install game files before starting a fresh match.
